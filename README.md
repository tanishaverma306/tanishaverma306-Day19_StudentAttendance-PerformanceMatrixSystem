Student Attendance & Marks Management System
This project is a C program that stores, displays, and analyzes student data using 2D arrays. It allows the user to input names, attendance, and marks of 5 students across 5 subjects, and then generates reports through a menu-driven interface. The program includes options to view attendance matrices, marks matrices, attendance reports, performance summaries, and grade evaluations.
Features
Store data for 5 students and 5 subjects
Display attendance and marks in matrix format
Generate attendance and performance reports
Grade calculation based on average marks
Menu-driven and user-friendly
Technologies Used
C Programming
2D Arrays
Loops & Conditional Statements
Switch-case Menu System
Project Objective
To understand and implement multi-dimensional arrays, menu-driven programming, and structured data handling in C.
